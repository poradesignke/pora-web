# PORA – generátor cenových ponúk

- `pricing.js` – pravidlá cenotvorby (Tom, 5. 10. 2026)
- `offer.js` – HTML šablóna ponuky podľa Canva „CP TEMPLATE“ (A4, Heebo + Lekton)
- `sample.mjs` – lokálne vygeneruje vzorové PDF cez Chromium

Plán: asistent na webe (Cloudflare Worker + Claude API) → výpočet → PDF (Browser Rendering) → e-mail; prvé týždne ponuky najprv Tomovi na schválenie.
